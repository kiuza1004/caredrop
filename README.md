## 1. 프로젝트 주요 특징

### ① 법적 방어 및 Zero-Effort 바이럴 설계 (방문판매법 완벽 준수)
1. **구매 강제성 100% 제거 (무료 발급 & 활동 기반 30일 연장):**
   - 음식을 한 번도 주문하지 않은 무료 회원도 **프리셋 태그 터치 1번(3초)**으로 즉시 무료 추천 카드 발급.
   - 30일 유효기간은 재주문 강제가 아닌, **링크를 통한 신규 유입(클릭) 1회 이상 발생 시 자동으로 30일 리셋 연장**.
2. **원클릭 큐레이션 카드 인용형 수익 배분 (콘텐츠 저작권 모델):**
   - 원작자(철수)의 추천 조합을 전달자(영희)가 원클릭 인용하여 `[철수 추천 × 영희 추천]` 합체 카드를 생성하고 홍보 수익 분배.
   - 최대 3인 고정: `구매자 1% + 전달자 1% + 원작자 1% = 총 3%`. (4단계 이상 시 슬라이딩되어 최근 2인 크리에이터 유지)
3. **Zero-Effort 원클릭 자동화:**
   - 주문 완료 유저: 방금 주문한 메뉴 구성으로 `[유저's Pick 꿀조합 세트 카드]` 자동 조립 완료.
   - 미주문 유저: 프리셋 태그 버튼(`👍 동네 찐맛집`, `🍺 야식 최고` 등) 터치 1번으로 자동 생성.
   - 전달자(영희): 공유 링크에서 `[나도 이 조합 추천하고 1% 받기]` 원클릭으로 합체 카드 즉시 완성.

## 2. 정산 및 쿠폰 작동 규칙

### ① 합체 카드(쿠폰) 우선순위 및 4가지 경우의 수 매칭
구매자(민수)가 단독 카드와 합체 카드를 모두 수신한 경우, 점주 예산(3%)을 최대한 활용해 많은 유저가 혜택을 받도록 **3인 정산이 가능한 '합체 카드'를 시스템이 최우선 자동 적용**합니다.

| 경우의 수 | 상태 조건 | 정산 결과 |
| :--- | :--- | :--- |
| **Case 1 (모두 유효)** | 전달자(영희) 유효 + 원작자(철수) 유효 | 민수(1%) + 영희(1%) + 철수(1%) = **총 3%** |
| **Case 2 (원작자 만료)** | 전달자(영희) 유효 + 원작자(철수) 만료 | 민수(1%) + 영희(1%) = **총 2%** (만료된 원작자 제외) |
| **Case 3 (전달자 만료)** | 전달자(영희) 만료 + 원작자(철수) 유효 | 민수(1%) + 철수(1%) = **총 2%** (살아있는 원작자 자동 전환) |
| **Case 4 (모두 만료)** | 모두 만료 또는 카드 미적용 | 민수(1%) 자체 적립 = **총 1%** (신규 카드 자동 발급) |

- **셀프 어뷰징 방어:** 본인 카드로 재주문 시 본인 전달자 1% 중복 수령은 차단되고 구매자 1% 및 상위 원작자 1%만 수령 (카드 유효기간 30일 연장).
- **후발 하위 합류 허용 정책:** 하위 전파 실적(`downline_count`)이 0명인 유저에 한해, 해당 매장 기준 생애 최초 1회 타인의 추천 카드를 인용하여 합체 카드로 편입 허용.

## 3. 자금 흐름 및 가맹점 간 교차 결제 상계 정산표

- **포인트 정책:** 현금 출금 금지, `1P = 1원`, 최소 사용 금액 없이 **전 가맹점 1원 단위 교차 결제 지원**.
- **교차 결제 상계 보전:**
  - A가게에서 적립된 포인트를 유저가 B가게에서 사용 시, 플랫폼의 '포인트 예치금 전용 계좌'에서 **B가게에 100% 현금으로 보전 지급**하여 점주 손실 0원 보장.
- **점주 정산 공식:**
  $$\text{최종 점주 수령액} = \text{총 주문매출} - \text{PG실비(3.0\%)} - \text{플랫폼수수료(2.5\%)} - \text{리워드부담금} + \text{교차포인트현금보전}$$
- **환불 어뷰징 방어:** 주문 시 `PENDING(적립 예정)` → 배달 완료 24시간 후 `CONFIRMED(가용 포인트)` 일괄 확정.

## 4. 로컬 실행 방법

### 요구 환경
- Node.js v18+ (Node v20 / v22 / v24 내장 SQLite 완벽 지원)

```bash
npm run test:engine

npm run dev

```

2. **원작자 카드 체험**: `/card/CHULSOO77` (철수's 바삭치킨 세트).
3. **전달자 합체 카드 체험**: `/card/YOUNGHEE88` (철수 추천 × 영희 추천 3인 합체 세트).
4. **민수 주문 및 3인 정산 확인**: 민수 로그인 후 영희 카드로 주문서(`/checkout`) 작성 시 3인 정산(3%) 자동 적용 확인 및 포인트 교차 결제 테스트.
5. **점주 관리자 및 정산표**: `/store-admin/1` 에서 배달 완료 처리 및 교차 결제 상계 정산 명세서 실시간 확인.
